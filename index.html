⚠️ Browser is blocking the data fetch

Your file is opened directly from your computer (file:// protocol). Chrome and Edge block external data requests in this mode, which is why the dashboard cannot load your Google Sheet.

Fix — 2 easy options:

Option A — Netlify Drop (recommended, 30 seconds, free)

  1. Go to app.netlify.com/drop
  2. Drag and drop this HTML file onto that page
  3. Netlify gives you a free link — open it and the dashboard loads

Option B — Python local server (if Python is installed)

  1. Open Command Prompt in the folder where the HTML file is saved
  2. Type: python -m http.server 8000 and press Enter
  3. Open your browser and go to http://localhost:8000
  4. Click the HTML file name to open the dashboard
